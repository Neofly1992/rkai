## 本轮发现并修复

| 优先级 | 问题及后果 | 最终处理与证据 |
| --- | --- | --- |
| P1 | SQLite 主库及 WAL/SHM/journal 的预置符号链接或硬链接可把数据库写入引向外部文件 | 打开 SQLite 前拒绝链接和非普通文件；8 个回归用例验证外部文件不变。此预检不是抵御同 UID 恶意进程在检查后替换目录的隔离边界 |
| P2 | 本地导入先无界复制，再校验声明大小；错误输入可能耗尽磁盘 | 先核对源大小，再按声明上限分块复制，增长时中断；回归验证超大输入未写入产物且任务为 failed |
| P2 | 损坏续传记录（数组、null、错类型 ETag、坏 JSON、深嵌套）可能抛出未受控异常 | 有界读取并校验状态类型，无法证明可续传时从零获取，最终仍检查大小/摘要 |
| P2 | 本地及已安装 manifest 存在绕过统一安全读取/大小限制的路径，深嵌套 JSON 可直接异常退出 | 使用统一有界读取，解析递归失败转 invalid_manifest；安装中的链接 manifest 报 corrupt。用户明确选择的导入根先规范化，兼容 macOS /tmp 等系统路径别名，manifest 叶及根内产物仍拒绝链接 |
| P2 | 镜像以 HTTP 200 返回 HTML/无效 manifest 时不回源 | 每个候选端点的 manifest 在接受前校验；坏镜像到正常源站的回归通过 |
| P2 | selector 解码发生在校验之后，编码的非法字符可绕过入口检查 | 解码后验证，非法 REF 返回 invalid_reference |
| P2 | doctor 按子串判断 API 符号，可能把 rknn_query_fake 当作 rknn_query；FIFO runtime 可能阻塞 | 精确匹配已定义的符号名（支持版本后缀），安全打开普通文件；相关回归通过。设备节点读取失败也受控报告 |
| P2 | 构造模型库时 recovery 失败未关闭 SQLite 连接 | 构造失败统一关闭已创建连接 |

另外限制 HTTP 元数据分块读取大小，避免一次读入未受控响应块。未改变数据库 schema 或删除旧数据，没有引入未发布实现的兼容层。
